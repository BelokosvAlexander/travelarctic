# Travel Arctic

Законченный самостоятельный путеводитель по русскому Северу. Проект развивался из учебного сайта 2023 года и Tilda-версии 2024 года; редакционная версия собрана в ноябре 2026 года.

Сайт отвечает на четыре вопроса: что представляет собой место, сколько времени разумно заложить, как построить поездку и какие условия нельзя считать гарантированными. Это не сервис бронирования и не расписание: изменчивые сведения вынесены на официальные сайты.

## Направления

- Кольский полуостров — Мурманск, Териберка, Хибины и северное небо.
- Кижи и Онежское озеро — архитектурный ансамбль, экспозиции, островные маршруты и ремёсла.
- Соловецкие острова — монастырский ансамбль, музей, память и природа архипелага.
- Земля Франца-Иосифа — подготовка к организованной высокоширотной экспедиции.

## Технологии

React 19, TypeScript, Vite и обычный CSS. Сборка полностью статическая.

- Нет backend, базы данных, регистрации, оплаты и бронирований.
- Нет localStorage и обещаний персонального сохранения данных.
- Памятка действительно скачивается как UTF-8 TXT через `Blob`.
- Печать и сохранение PDF используют системный диалог `window.print()`.
- Адаптивная вёрстка, клавиатурная навигация, видимый focus, `prefers-reduced-motion` и отдельные стили печати.

## Локальный запуск

```bash
npm install
npm run images
npm run dev
```

Команда `npm run images` скачивает оригиналы с лицензионных источников и создаёт локальные WebP/JPEG в `public/images/`. Для неё нужен доступ к Pexels и Wikimedia Commons. Если фотографии уже есть в этом каталоге, повторять загрузку не требуется. Можно восстановить один источник, например `npm run images -- teriberka`; доступны идентификаторы `teriberka`, `kizhi`, `solovki`, `franz`.

Проверка production-сборки:

```bash
npm run build
npm run preview
```

Готовые статические файлы появляются в `dist/`. Для проверки качества кода также доступен `npm run lint`.

## Яндекс Метрика

В `index.html` подключён существующий счётчик **92093763** с картой кликов, отслеживанием ссылок, точным показателем отказов и Вебвизором. Для посетителей без JavaScript предусмотрен noscript-пиксель.

В `App.tsx` функция `trackGoal` отправляет события:

- `destination_open` — открытие направления; параметр `destination` содержит его идентификатор;
- `memo_download` — скачивание памятки;
- `memo_print` — вызов печати;
- `official_source` — переход к официальному источнику.

Чтобы видеть их как отдельные отчёты, в интерфейсе Метрики нужно один раз создать JavaScript-события с этими идентификаторами. До создания целей данные продолжают поступать в общую статистику.

## Редакционные правила

- Длительность и сезонность — ориентиры, а не обещания.
- Не обещать северное сияние, встречи с животными, высадки, открытые дороги и точные стыковки.
- Не дублировать цены, расписания, правила продажи билетов и другую быстро устаревающую информацию.
- Раз в год проверять смысловую точность текстов, ссылки и лицензии; при изменении обновлять `REVIEW_DATE` в `src/App.tsx`.
- Официальные источники: `murmansk.travel`, `meteoinfo.ru`, `kizhi.karelia.ru`, `solovky.ru`, `rus-arc.ru`, `mchs.gov.ru`.

Путеводитель не заменяет прогноз, инструктаж, правила территории и решения организатора экспедиции. Единый номер экстренных служб — 112.

## Публикация на GitHub Pages

Workflow `.github/workflows/main.yml` после каждого push в `main` устанавливает зависимости, восстанавливает фотографии командой `npm run images`, собирает production-версию в `dist/` и публикует именно этот каталог через официальные GitHub Pages Actions.

В настройках репозитория **Settings → Pages → Build and deployment** должен быть выбран **Source: GitHub Actions**. Вариант **Deploy from a branch → main / root** для этого проекта не подходит: в корне находятся исходники Vite, а не готовые файлы production-сборки.

Повторить запуск вручную можно на вкладке **Actions → Deploy to GitHub Pages → Run workflow**. Публичный адрес проекта: `https://belokosvalexander.github.io/travelarctic/`.

После `npm run build` каталог `dist/` можно разместить и на другом статическом хостинге без серверной логики. В рабочем пространстве Kimi версия сохраняется отдельно для предварительного просмотра; сохранение версии не означает публикацию на GitHub Pages.

## Фотографии

Во время работы сайта файлы загружаются локально из WebP/JPEG и не зависят от внешних фотохостингов. Каталог можно восстановить командой `npm run images`. Авторы, исходные страницы и лицензии перечислены в [CREDITS.md](./CREDITS.md) и в подвале сайта. Код проекта не передаёт права на фотографии: при их дальнейшем использовании необходимо сохранять соответствующую атрибуцию и условия лицензий.
